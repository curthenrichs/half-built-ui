# Popout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `Popout` component and island in the @half-built packages that open a short rich-text note from a table cell: an anchored box on desktop, a modal bottom sheet on phones. The blog's filament table is the first consumer.

**Architecture:** `placeTip` moves from `link-tip.ts` to `core/placement.ts` so two islands share it. A new `scripts/popout.ts` island owns one `<dialog class="popout">` per page, fills it from the clicked trigger's `<template>`, and opens it with `show()` (anchored) or `showModal()` (sheet) depending on the phone breakpoint at open time. `components/Popout.astro` renders the trigger and template. `popout.css` carries the boxed chrome. It ships as 0.11.0 through Curt's tag release, then the blog swaps its tooltip workaround for the component.

**Tech Stack:** Astro 5.18 components, TypeScript (strict, typed ESLint), vitest with jsdom, puppeteer-core browser suite, stylelint, npm workspaces (half-built-ui), exact-pinned registry packages (blog).

**Spec:** `half-built-ui/docs/superpowers/specs/2026-09-26-popout-design.md`

## Global Constraints

- Mode is `sheet` when `matchMedia("(max-width: 768px)")` matches (the `BP_PHONE_MAX` mirror in `core/breakpoints.ts`), `anchored` otherwise, read at every open, never cached. No `matchMedia` (jsdom) means `anchored`.
- One `<dialog class="popout">` per document. One open at a time.
- Chrome uses only existing tokens and patterns: `--stroke`, `--rule`, `--surface`, `--ink`, `--shadow`, `--veil`, `.boxed-label`, `.micro-label`, `.icon-box`, `ICON_X`. No new colors.
- New token `--z-popout: 19` (under `--z-tooltip: 20`, over `--z-scroll-top: 17`).
- No prose width caps. The anchored box's `max-width` caps a floating UI surface, which the spec clears explicitly; nothing else in this plan sets a width on text.
- Version: 0.11.0 across `@half-built/astro`, `@half-built/css`, `@half-built/tooling` (fixed versioning; `site/test/release.test.ts` enforces it). The site's three exact pins move to 0.11.0 with them.
- Release is Curt's step: merge to main, tag `v0.11.0`, push the tag. Never tag or push in this plan.
- No shims: `link-tip.ts` stops exporting `placeTip`; every caller imports from `core/placement`.
- Blog: never patch `node_modules`; changes arrive by pin bump. Restart any running `astro dev` after the bump and after `npm test`.
- Blog: its dev tree holds uncommitted Bench Hardware edits. Task 6 does not start until Curt says how to handle them.
- No em dashes anywhere (code, comments, docs, content). Site demo copy is the ui site's impersonal active voice.
- `site/test/release.test.ts`'s bump check fails from Task 1's first package change until Task 5 bumps the version. That single failure is expected in Tasks 1 to 4; any other failure is not.
- Formatting is tooling-enforced: `npx prettier --write <files>` and `npm run lint:fix` on touched files, never a hand whitespace pass.

## Review Focus

1. Switching straight from one open popout to another: `dialog.close()` fires its `close` event asynchronously in real browsers, so a naive close handler would wipe the second popout's content a tick later. Pinned in Task 3 (a queued close event after a reopen leaves the new popout intact) and Task 4's browser test (two consecutive triggers).
2. Pressing the open trigger again: an outside-press handler that counts the trigger as "outside" closes on pointerdown and the click reopens it. Expected: the popout closes and stays closed. Pinned in Task 3.
3. A phone that resizes without crossing the breakpoint (URL bar collapse, keyboard): the sheet must stay open. Only a breakpoint crossing closes. Pinned in Task 3. This refines the spec's "resize closes" line; Task 1 updates the spec to match.
4. A popout inside a horizontally scrolled `.table-scroll`: the surface must not be clipped by the scroller and must follow the trigger when the scroller moves. Pinned in Task 4's browser test.
5. A trigger with no `<template>` sibling (a consumer hand-writing markup): clicking it must do nothing and throw nothing. Pinned in Task 3.

`packages/astro/src/scripts/popout.ts`:

```ts
/* Popout (spec docs/superpowers/specs/2026-09-26-popout-design.md):
   secondary context for tables and data viz. One island, one real
   <dialog> per page. A click on a trigger fills it from the template
   right after that trigger and opens it anchored beside the trigger
   (desktop) or as a modal bottom sheet (phone width, decided at each
   open). Chrome lives in @half-built/css popout.css. */

import { claim, release, type Island, type IslandHandle } from "./core/island";
import { docOf, el, iconButton } from "./core/dom";
import { ICON_X } from "./core/icons";
import { BP_PHONE_MAX } from "./core/breakpoints";
import {
  placeTip,
  EDGE,
  type AnchorRect,
  type ViewportSize,
} from "./core/placement";

export type PopoutMode = "anchored" | "sheet";

/* The tip edge plus the close box's 17px straddle, so the box never
   lands with its close control off screen. */
const POPOUT_EDGE = EDGE + 18;

/* The label straddles the box's top rule by about 12px; this keeps it
   off the trigger it belongs to. */
const LABEL_CLEAR = 16;

export const SWIPE_CLOSE = 60;

export interface PopoutOptions {
  selector?: string;
  edge?: number;
  closeLabel?: string;
}

interface MediaHost {
  matchMedia?: (q: string) => { matches: boolean };
}

/* Widened like link-tip's guard: jsdom has no matchMedia, and the plain
   Window type always declares it. */
export function popoutMode(win: MediaHost | null): PopoutMode {
  return win?.matchMedia?.(`(max-width: ${BP_PHONE_MAX}px)`).matches
    ? "sheet"
    : "anchored";
}

export function offscreen(r: AnchorRect, vp: ViewportSize): boolean {
  return r.bottom < 0 || r.top >= vp.height || r.right < 0 || r.left >= vp.width;
}

export function isSwipeClose(
  startY: number | null,
  endY: number,
  threshold: number = SWIPE_CLOSE,
): boolean {
  return startY !== null && endY - startY >= threshold;
}

export const mountPopouts: Island<PopoutOptions> = (
  root,
  options = {},
): IslandHandle => {
  const {
    selector = ".popout-trigger",
    edge = POPOUT_EDGE,
    closeLabel = "Close",
  } = options;

  const doc = docOf(root);
  const html = doc.documentElement;

  if (!claim(html, "popout")) {
    return {
      destroy(): void {
        /* already claimed elsewhere: nothing here to tear down */
        return;
      },
    };
  }

  const win = doc.defaultView;
  const media = win as MediaHost | null;

  const surface = el(doc, "dialog", "popout");
  surface.setAttribute("aria-labelledby", "popout-label");
  surface.tabIndex = -1;
  const label = el(doc, "span", "popout-label boxed-label micro-label");
  label.id = "popout-label";
  const closeBtn = iconButton(doc, "popout-close icon-box", closeLabel, ICON_X);
  const body = el(doc, "div", "popout-body");
  surface.append(label, closeBtn, body);
  doc.body.append(surface);

  let current: HTMLElement | null = null;
  let mode: PopoutMode = "anchored";
  let frame = 0;
  let swipeStart: number | null = null;

  const viewport = (): ViewportSize => ({
    width: html.clientWidth,
    height: html.clientHeight,
  });

  const triggerFor = (t: EventTarget | null): HTMLElement | null => {
    if (!(t instanceof Element)) return null;
    const hit = t.closest(selector);
    return hit instanceof HTMLElement ? hit : null;
  };

  /* Every way out lands here, synchronously. dialog.close() queues its
     close event in real browsers, so the listener below only acts when
     the dialog is actually shut: a late event after a reopen is
     ignored. */
  const finish = (): void => {
    const opener = current;
    if (!opener) return;
    current = null;

    if (frame) {
      win?.cancelAnimationFrame(frame);
      frame = 0;
    }

    if (surface.open) surface.close();
    surface.classList.remove("is-anchored", "is-sheet");
    surface.style.left = "";
    surface.style.top = "";
    body.replaceChildren();
    html.classList.remove("popout-open");
    opener.setAttribute("aria-expanded", "false");
    opener.classList.remove("is-open");
    opener.focus({ preventScroll: true });
  };

  const place = (): void => {
    if (!current) return;
    const r = current.getBoundingClientRect();

    const anchor: AnchorRect = {
      left: r.left,
      right: r.right,
      top: r.top - LABEL_CLEAR,
      bottom: r.bottom + LABEL_CLEAR,
    };

    const pos = placeTip(
      anchor,
      surface.getBoundingClientRect(),
      viewport(),
      "below",
      "start",
      edge,
    );

    surface.style.left = `${pos.x}px`;
    surface.style.top = `${pos.y}px`;
  };

  const open = (trigger: HTMLElement): void => {
    const tpl = trigger.nextElementSibling;
    if (!(tpl instanceof HTMLTemplateElement)) return;
    finish();
    current = trigger;
    mode = popoutMode(media);
    label.textContent = trigger.dataset.popoutLabel ?? "";
    body.replaceChildren(tpl.content.cloneNode(true));
    trigger.setAttribute("aria-expanded", "true");
    trigger.classList.add("is-open");

    if (mode === "sheet") {
      surface.classList.add("is-sheet");
      surface.showModal();
      html.classList.add("popout-open");
    } else {
      surface.classList.add("is-anchored");
      surface.show();
      place();
    }

    surface.focus({ preventScroll: true });
  };

  const onClick = (ev: MouseEvent): void => {
    const trigger = triggerFor(ev.target);

    if (trigger) {
      if (trigger === current) finish();
      else open(trigger);
      return;
    }

    /* The dialog has no padding of its own (popout.css), so a click on
       the element itself is a click on the sheet's backdrop. */
    if (ev.target === surface && mode === "sheet") finish();
  };

  /* Anchored only; the sheet's outside is its backdrop. A press on any
     trigger is left to the click handler, or pressing the open trigger
     would close here and reopen on click. */
  const onPointerDown = (ev: Event): void => {
    if (!current || mode !== "anchored") return;
    const t = ev.target;
    if (t instanceof Node && surface.contains(t)) return;
    if (triggerFor(t)) return;
    finish();
  };

  const onKey = (ev: KeyboardEvent): void => {
    if (ev.key !== "Escape" || !current) return;
    ev.preventDefault();
    finish();
  };

  const settle = (): void => {
    frame = 0;
    if (!current) return;

    if (offscreen(current.getBoundingClientRect(), viewport())) {
      finish();
      return;
    }

    place();
  };

  const onScroll = (): void => {
    if (!current || mode !== "anchored" || frame) return;
    frame = win?.requestAnimationFrame(settle) ?? 0;
  };

  const onResize = (): void => {
    if (!current) return;

    if (popoutMode(media) !== mode) {
      finish();
      return;
    }

    if (mode === "anchored") place();
  };

  const onClose = (): void => {
    if (!surface.open) finish();
  };

  const onTouchStart = (ev: TouchEvent): void => {
    swipeStart =
      mode === "sheet" && body.scrollTop === 0
        ? (ev.touches.item(0)?.clientY ?? null)
        : null;
  };

  const onTouchEnd = (ev: TouchEvent): void => {
    const y = ev.changedTouches.item(0)?.clientY;
    if (y !== undefined && isSwipeClose(swipeStart, y)) finish();
    swipeStart = null;
  };

  const onCloseBtn = (): void => {
    finish();
  };

  doc.addEventListener("click", onClick);
  doc.addEventListener("pointerdown", onPointerDown);
  doc.addEventListener("keydown", onKey);
  /* capture: scroll does not bubble from inner scrollers (.table-scroll) */
  doc.addEventListener("scroll", onScroll, true);
  win?.addEventListener("resize", onResize);
  surface.addEventListener("close", onClose);
  surface.addEventListener("touchstart", onTouchStart, { passive: true });
  surface.addEventListener("touchend", onTouchEnd, { passive: true });
  closeBtn.addEventListener("click", onCloseBtn);

  return {
    destroy(): void {
      finish();
      doc.removeEventListener("click", onClick);
      doc.removeEventListener("pointerdown", onPointerDown);
      doc.removeEventListener("keydown", onKey);
      doc.removeEventListener("scroll", onScroll, true);
      win?.removeEventListener("resize", onResize);
      surface.remove();
      release(html, "popout");
    },
  };
};
```
